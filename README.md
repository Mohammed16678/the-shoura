# شورى — تطبيق ويب اجتماعي

تطبيق ويب عربي باتجاه RTL، مبني بواجهة HTML/CSS/JavaScript وخلفية ASP.NET Core Web API. الواجهة والـ API والوسائط تعمل تحت نفس النطاق. كود أندرويد السابق محفوظ منفصلاً داخل `archive/android_app`، ولا يدخل في تشغيل أو بناء الموقع.

## تشغيل الموقع محلياً

1. ثبّت .NET 10 SDK.
2. من جذر المستودع شغّل `dotnet run --project backend/Shoura.API/Shoura.API.csproj`.
3. افتح العنوان المحلي الذي يظهر في الطرفية. للتحقق من الخادم أضف `/health`.

في التطوير يستخدم الخادم SQLite تلقائياً. افتح الموقع وسجّل حساباً (كلمة المرور 12 حرفاً على الأقل) لتجربة النشر والتعليقات والإعجاب وإعادة المشاركة. التسجيل الصوتي من المتصفح يحتاج إذن الميكروفون واتصالاً آمناً، ويقتصر على 60 ثانية.

## النشر عبر GitHub وRender

ارفع جذر المستودع إلى GitHub، ثم أنشئ في Render خدمة **Web Service** واربطها بالمستودع واختر **Docker**. ملف `Dockerfile` في الجذر يبني تطبيق .NET ويشغله على المنفذ 10000. أضف متغيرات `.env.example` من لوحة Render مع القيم الحقيقية. لا ترفع `.env` أو الأسرار إلى Git.

## ربط Supabase

في Supabase أنشئ مشروع PostgreSQL وBucket عام باسم `shoura-media`، ثم عيّن:

- `SHOURA_DATABASE_PROVIDER=Postgres`
- `SHOURA_CONNECTION_STRING` بسلسلة اتصال PostgreSQL من Supabase.
- `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` و`SUPABASE_STORAGE_BUCKET` للوسائط.
- `SHOURA_AUTH_SIGNING_KEY` كسِر عشوائي قوي وفريد.

مفتاح `service_role` سر خادمي لا تضعه في الواجهة أو GitHub. يطبق الخادم ترحيلات قاعدة البيانات عند بدء التشغيل ويرفع الصور والفيديو والصوت إلى Supabase عند ضبط مفاتيح التخزين. من دونها يستخدم تخزيناً محلياً ملائماً للتطوير فقط.

## ما يدعمه الإصدار الحالي

- تسجيل الحساب والدخول عبر JWT، والخلاصة، والنشر، والإعجاب، وإعادة المشاركة، والتعليقات.
- رفع الصور والفيديو والصوت. يرفض الخادم الفيديو الأكبر من 20 ميجابايت، ويستخرج الهاشتاقات ويحفظها مع المنشور.
- واجهة عربية متجاوبة، البحث بالهاشتاق، مساحات مواضيع، أنواع مشاركة، ومؤشر للهاشتاقات المتداولة.

بعض الأفكار المعروضة، مثل التحديات وترتيب أصحاب الحلول، إثبات التجربة بصورة، التصويت، يوميات التقدم والملصقات، تحتاج استكمال API وقاعدة البيانات. حد مدة التسجيل مطبق في المتصفح؛ الخادم يتحقق من حجم الملف ونوعه وتوقيعه لكنه لا يحلل مدة الصوت.

## التحقق

تم التحقق من بناء API عبر `dotnet build backend/Shoura.API/Shoura.API.csproj --no-restore` ومن صياغة JavaScript. قد يظهر تحذير NuGet `NU1900` إذا تعذر الاتصال بخدمة بيانات الثغرات. لم يتم اختبار الاتصال بمشروع Supabase أو نشر Render فعلي.
